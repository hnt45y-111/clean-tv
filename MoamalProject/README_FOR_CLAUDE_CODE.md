# مشروع مغامرة القراءة (للطفل مؤمل) - الإصدار 2.25
المستخدم عراقي، يكتب بالعربي العراقي، وردّك دايماً بالعربي. لا تضف نصوص أو مكونات من عندك، ولا تغيّر الميزات القديمة.

## الهيكل
- www/index.html : التطبيق الكامل (ملف واحد، مبني من source/ + صور الصفحات base64).
- source/ : patch.py (يطبّق التعديلات على template_base.html)، style.css, quran.js, icons.js, book.js, build.sh.
- android/ : غلاف WebView (MainActivity.java, AndroidManifest.xml v2.25 / versionCode 225). يُبنى بدون Gradle عبر build.ps1 على ويندوز (نفس keystore: moamal.keystore، كلمة السر moamal123، لازم نفس المفتاح حتى ينصب فوق القديم، وزيادة versionCode).
- gen_voices.py : يولّد أصوات مايكروسوفت (edge-tts ar-IQ-RanaNeural) لكل عبارة في phrases.json.
- fetch_quran.py : ينزّل نص وصوت جزء عمّ والفاتحة (المنشاوي مع الأطفال).
- phrases.json : كل العبارات (1271، ~25 ألف حرف) مصدرها ALLPHRASES() في الـHTML.

## نظام الصوت
hash = FNV-1a على UTF-16 → voices/<hash>.mp3 ، و voices/index.js يضبط window.VOICES. الدالة say(text|[parts]) تفحص: تسجيل الطفل (IndexedDB) ← mp3 جاهز ← TTS احتياطي.

## المهمة الحالية (خفض الأصوات)
المستخدم يريد تقليل الأصوات الجاهزة وتوليدها من ElevenLabs (حد ~10000 حرف) بدل 25 ألف:
1. voice_texts/elevenlabs_full.txt : القائمة النهائية (717 سطر، 9312 حرف)، كل سطر مقطع مستقل. المستخدم يولّدها من ElevenLabs.
2. عدّل التطبيق حتى يركّب الجمل من هذي المقاطع عبر say([...parts]) بدل العبارات الكاملة. مثال: "وين" + "حرف الباء" لا يوجد؛ الجمل الأساسية للحروف موجودة كاملة (وين حرف X؟، هذا حرف X، أي صورة تبدأ بحرف X؟، يلا نفقّع فقاعات حرف X، هسه نكتب حرف X وحده)، أما: "هسه نكتب في أول/وسط/آخر الكلمة، مثل كلمة" + كلمة، "أي شكل يناسب كلمة" + كلمة، "شنو الحرف الناقص من كلمة" + كلمة، "وين صورة" + كلمة، "شنو الرقم اللي بعد/قبل" + رقم، "واو! كتبنا" + حرف + "بكل أشكاله".
3. احذف من الكلام: أسماء الأطفال وذكر الاسم، الكلام عند التنقل (أي لعبة/درس/حرف)، الكلام الجانبي (دغدغتني، نار نار، المستوى، الأوسمة)، صوت واجهة النشيد (بدون صوت). التشجيع فقط: "أحسنت" / "صح" / "حاول مرة ثانية" (بلا نسخ ولد/بنت).
4. الهدايا: "عفية! بابا راح يجيبلك" (أو يجيبلج) + اسم الهدية + "إذا حفظت. تدلل!".
5. ما يُحذف من الصوت الجاهز يرجع للـTTS الاحتياطي (صوت النظام) بدل mp3.
6. حدّث ALLPHRASES() وphrases.json وصدّره بـ Playwright، واعمل سكربت يستقبل مجلد mp3 المولّدة (كل ملف بترتيب الأسطر) ويسمّيها <hash>.mp3 ويكتب voices/index.js.
7. ارفع الإصدار إلى 2.25 / versionCode 225.
