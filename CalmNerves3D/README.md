# هدّي أعصابك 3D — نسخة Java أصلية (libGDX / OpenGL)

بديل كامل عن نسخة HTML: لعبة **Java أصلية** برسم GPU، خلفية **3D حقيقية** (كاميرا منظورية بطبقات تتحرك مع ميلان الموبايل)، صوت أصلي، واهتزاز.

| وحدة | الدور |
|---|---|
| `core` | كل اللعبة (شاشات، تحديات، أوضاع، بنك أسئلة، ترجمات، مؤثرات) |
| `desktop` | تشغيل واختبار على الكمبيوتر (`gradle :desktop:run`) + `ShotGame` يصوّر كل الشاشات |
| `android` | الـ APK (يُبنى بـ GitHub Actions: `.github/workflows/calmnerves3d.yml`) |
| `assets` | صور (مقصوصة من المرجع)، خط Cairo، أصوات WAV، `data/*.json` |

## إضافة محتوى
- **سؤال:** أضفه في `assets/data/questions.json` (`c` تصنيف، `d` صعوبة 1-3، `t` سؤال بـ5 لغات `[ar,en,tr,fr,es]`، `a` إجابات لكل لغة والصحيحة أولاً).
- **لغة:** أضف كتلة في `strings.json` ولغتها في `I18n.LANGS`، وعنصراً سادساً لكل سؤال.
- **نوع تحدٍّ:** صنف يرث `Challenge` (انظر `Challenges.java`) وسجّله في `IDS` / `WEIGHT` / `MIN_LEVEL` / `create()`.

## ملاحظات
- النص العربي يُشكَّل بمحرك المنصة (Java2D على الكمبيوتر، `StaticLayout` على أندرويد) ثم يُرسم كنسيج.
- الإيموجي (🔒 والقبعات) يعتمد على خط النظام (يظهر على أندرويد، وقد يظهر مربعاً على الكمبيوتر).
- مشاركة «تحدي الأصدقاء» ترسل رمزاً نصياً (`CALM-seed-level`)، الدخول بالرمز غير مكتمل بعد.
