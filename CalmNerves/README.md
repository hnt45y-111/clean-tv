# هدّي أعصابك — Calm Your Nerves

لعبة تحدّيات HTML5 عمودية (بدون أي مكتبة خارجية، تعمل أوفلاين) + غلاف أندرويد (WebView) لبناء APK.

## التشغيل
```
cd www && python3 -m http.server 8000     # ثم افتح http://localhost:8000
```
## بناء الـ APK
يبنيه الـ workflow `.github/workflows/calmnerves.yml` تلقائياً عند أي تعديل في `CalmNerves/` (الملف يظهر في Actions → Artifacts وفي Releases).
محلياً (يحتاج Android SDK + Gradle 8.7): `cd android && gradle assembleDebug` ← `app/build/outputs/apk/debug/app-debug.apk`.
مجلد `www/` هو مصدر الـ assets مباشرة، فلا نسخ مكرّرة.

## البنية
| ملف | الدور |
|---|---|
| `www/js/i18n.js` | اللغات الخمس وكل نصوص الواجهة |
| `data/questions.js` | بنك الأسئلة والألغاز |
| `js/challenges.js` | أنواع التحديات (سجل `G.CH`) والزعيم |
| `js/character.js` | الشخصية والزعيم والتاج (SVG) + الأفاتارات والقبعات |
| `js/core.js` | الحفظ، الـ RNG بالـ seed، الصوت المُولَّد، الاهتزاز، المؤثرات |
| `js/app.js` | الشاشات والمحرّك (مؤقت، قوى، كومبو، تحوّلات مفاجئة، أوضاع اللعب) |

## إضافة سؤال
أضف عنصراً في `G.Q` (الترتيب دائماً `[ar, en, tr, fr, es]` والإجابة الصحيحة **أول** عنصر في كل قائمة):
```js
{c:'geo', d:1, t:['س؟','Q?','S?','Q ?','¿P?'],
 a:[['صح','x','y','z'],['right','x','y','z'],['doğru','x','y','z'],['juste','x','y','z'],['bien','x','y','z']]}
```
`c` التصنيف، `d` الصعوبة 1–3. اللعبة تتتبّع الأسئلة المعروضة ولا تكرّر قبل استنفاد البنك.

## إضافة لغة
1. أضف `xx: {name, rtl}` في `G.LANGS` وكتلة `G.STR.xx` (انسخ `en` وترجمها)، وأسماء الألوان في `G.COLORS.xx`.
2. أضف عنصراً سادساً لكل سؤال في `t` و`a` وأضف `'xx'` إلى مصفوفة اللغات في `G.qForCtx` (`challenges.js`) وفي `speak()` (`app.js`).

## إضافة نوع تحدٍّ
في `challenges.js`:
```js
G.CH.push({ id:'mine', weight:2, minLevel:5, time:function(c){return G.timerSec(12,c)},
  mount:function(ctx){ ctx.prompt('...'); /* ابنِ الواجهة داخل ctx.root */ /* ctx.win() أو ctx.fail() */ return function(){/*تنظيف*/} } });
```
المحرّك يختاره تلقائياً بقاعدة "لا تكرار متتالي" بحسب `weight`. `ctx.rng` مرتبط بالـ seed (للتحدّي المشترك).

## ما هو غير مكتمل / ملاحظات صريحة
- **الأصول البصرية** (الشخصيات، الزعيم، الشعار، الأزرار، اللوحات الخشبية، التاج، أيقونات الكرة/السيارة/النجمة/الهدية، الإيموجي…) **مقصوصة من صورة المرجع نفسها** في `www/img/` (النصوص مُفرَغة منها ويُكتب النص الحيّ فوقها بكل لغة). دقتها محدودة لأن المرجع منخفض الدقة (~300px للشاشة)، وبعض الحواف/الخلفيات مقصوصة تقريبياً. للدقة الكاملة استبدل ملفات `img/*.png` بنسخ عالية الدقة بنفس الأسماء، دون تغيير الكود.
- الخريطة (المسار والعقد) والخلفية ورسوم الكؤوس مبنية بالكود وليست من المرجع.
- بنك الأسئلة الحالي ~30 سؤالاً لكل لغة (وليس مئات)؛ البنية جاهزة للتوسعة.
- **المبارزة** محلية (تمرير الجهاز بين لاعبين بنفس الـ seed)، ولوحة الصدارة الأسبوعية محلية على الجهاز — الأونلاين الحقيقي يحتاج سيرفر.
- الموسيقى والمؤثرات مُولَّدة برمجياً (WebAudio) وليست مقطوعات مسجّلة.
- لم يُبنَ الـ APK داخل هذه البيئة (لا Android SDK ولا وصول لخوادم Google)، ويُبنى عبر GitHub Actions.
