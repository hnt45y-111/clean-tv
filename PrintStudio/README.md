# Print Studio — مركز الطباعة والسكانر والتعرف الذكي

تطبيق Windows مكتبي (Electron) واجهته عربية بالكامل (RTL) وبهوية «كوميكس» داكنة. الفكرة: **الورقة الممسوحة تصبح مستنداً رقمياً قابلاً للتحرير** (Word / Excel) لا مجرد صورة.

## التشغيل والبناء
```bash
cd PrintStudio
npm install          # يثبّت الاعتماديات وينسخ pdf.js والخطوط وبيانات OCR (عربي/إنجليزي) محلياً
npm start            # تشغيل التطبيق (Windows 10/11)
npm test             # اختبارات المحرك (بلا واجهة)
npm run e2e          # اختبارات الواجهة بمتصفح Chromium (يتطلب playwright) عبر tools/devserver.js
npm run dist         # مثبّت NSIS (يُبنى على Windows؛ أو عبر .github/workflows/printstudio.yml)
```

## البنية
| الوحدة | الملفات |
|---|---|
| العملية الرئيسية + طبقة preload آمنة (`contextIsolation`، `sandbox`، بلا `nodeIntegration`، IPC بقائمة بيضاء) | `src/main/` |
| الطابعات والسكانر (PowerShell: Win32_Printer / PrintManagement / **WIA** عبر COM) | `src/core/winhw.js` |
| OCR (Tesseract `ara+eng` محلي) + تحليل التخطيط + كشف الجداول (معالجة صور بلا OpenCV) | `ocr.js` `recognize.js` `docmodel.js` `tables.js` |
| التصدير: DOCX حقيقي (`docx`)، XLSX حقيقي (`exceljs`)، PDF (`pdf-lib`)، صور (`sharp`) | `export-*.js` `pdfkit.js` `imaging.js` |
| الهويات والباجات (ترتيب + PDF/صورة/Word بصور عائمة مستقلة) | `idlayout.js` |
| قاعدة SQLite (sql.js) للإعدادات والأرشيف والسجل | `db.js` `settings.js` `app.js` |
| الواجهة العربية (صفحات: السكانر، التعرف الذكي، الهويات، الطباعة، الطابعات، PDF، الأرشيف، الإعدادات) | `src/renderer/` |

## إضافات الإصدار الثاني
* **قارئ PDF** كامل: تمرير مستمر، تكبير، ملاءمة، تدوير، صفحتان، وضع ليلي، ملء الشاشة، مصغّرات وفهرس، بحث (يتجاهل التشكيل)، تحديد النص ونسخه، قلم/تظليل/نص مع حفظ نسخة جديدة بالتعليقات، تعرّف على صفحة، حفظ صفحة كصورة، استخراج صفحة.
* **اتجاه الطباعة تلقائي حسب كل صفحة** (مع خيار طولي/عرضي) ودقة الطباعة، ومعاينة تعرض الاتجاه الفعلي.
* **كشف الأجهزة المتصلة بالحاسوب** (USB/PnP) حتى لو لم يُثبَّت تعريفها، مع أزرار إضافة طابعة وإعدادات Windows.
* **الهويات على A4:** الأمامي يمين/يسار باختيارك، ومعاينة نهائية مطابقة للتصدير.
* **نسخ سريع** (مسح ثم طباعة)، واختيار دقة/لون/حجم المسح من الصفحة الرئيسية.
* اختبار **Electron حقيقي** (`tests/e2e/electron.js`) على Linux بشاشة افتراضية.

## ما تم التحقق منه فعلاً
* **اختبارات المحرك (24):** تسمية الملفات بلا تكرار امتداد، حفظ الإعدادات بعد إعادة التشغيل، OCR عربي/إنجليزي على نص وجدول، كشف شبكة الجدول (صفوف/أعمدة/دمج)، بنية DOCX (فقرات `bidi`، جداول، دمج، **بلا صور مسطّحة**) وفتحه في LibreOffice، XLSX بخلايا وأرقام ودمج وRTL، أدوات PDF، تخطيط الهويات (PDF/PNG/Word)، تحليل مخرجات PowerShell وأخطاء WIA، وحدود أمان IPC والبروتوكولات.
* **اختبارات الواجهة (e2e، متصفح حقيقي):** معالج الطابعة، مسح متعدد الصفحات مع «مسح صفحة أخرى +»، السحب لإعادة الترتيب، التصدير باسم/مجلد محفوظ، جدول→Excel مع تعديل الخلايا والصفوف والأعمدة والفرز، خطاب→Word مع تعديل الخط والحجم، محرر الهويات (سحب/تكبير/تدوير)، خلفية اللوحة الرئيسية فقط وبقاؤها بعد إعادة التحميل، أدوات PDF، الأرشيف والبحث وإعادة الطباعة.

## ما لم يُختبر ولماذا (بصراحة)
* **أجهزة حقيقية:** بيئة التطوير Linux بلا Windows ولا سكانر ولا طابعة. سكربتات PowerShell (WIA/الطباعة/طابور الطباعة/`printui`) كُتبت بحسب وثائق Windows ومحلَّل مخرجاتها مُختبَر بمحاكاة، **لكنها لم تُشغَّل على جهاز حقيقي** — جرّبها على سكانرك وطابعتك أولاً. خادم التطوير يحاكي الأجهزة صراحةً (للاختبار فقط) ولا يدخل في الإنتاج؛ وخارج Windows يرفض التطبيق العمل بدل اختلاق حالة.
* **تشغيل Electron نفسه** (تعذّر تنزيل ملفه التنفيذي في بيئة التطوير) وبناء المثبّت: اختبرت العملية الرئيسية بـ electron وهمي، والواجهة بـ Chromium عبر خادم تطوير. أول تشغيل على Windows قد يكشف تفاصيل لم تظهر هنا.
* **TWAIN غير مدعوم:** الاتصال بالسكانر عبر WIA فقط. الأجهزة التي تعمل بـ TWAIN وحده لن تظهر. التغذية التلقائية (ADF) مبرمجة في السكربت لكن غير مفعّلة في الواجهة.

## حدود دقة التعرف (لا وعود زائفة)
* Tesseract يخطئ أحياناً (أمثلة ظهرت في الاختبار: «أيام»→«أياه»، وخلية «علي حسن» لم تُقرأ). لذلك: تُعلَّم الكلمات/الخلايا منخفضة الثقة باللون الأصفر، وتظهر نسبة الثقة، وتتوفر شاشة مراجعة وتحرير **قبل** التصدير.
* الجداول بحدود واضحة تُكشف بدقة؛ **الجداول بلا حدود** تُخمَّن من مواضع الكلمات وتُعرَّف كـ«تخمين».
* بنية Word تُعاد كفقرات وعناوين وقوائم وجداول وتحاذيات وأحجام تقريبية — **ليست نسخة مطابقة للأصل**. الشعارات والصور داخل الصفحة لا تُستخرج تلقائياً (يمكن إدراج صورة الأصل بعد النص أو إضافة صور يدوياً).
* الخط اليدوي والصور الباهتة أو التالفة غير مدعومة.
* الطباعة تمر عبر Chromium (صفحات PDF تُحوَّل إلى صور بدقة 200 DPI قبل الإرسال).
