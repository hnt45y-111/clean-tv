# لانشر ثنائي الواجهة — Samsung One UI و Google Pixel

لانشر أندرويد حقيقي (تطبيق `HOME`) مكتوب بـ Kotlin وJetpack Compose، يحتوي **واجهتين كاملتين مستقلتين** (سامسونج One UI وجوجل Pixel) فوق **محرك واحد مشترك**. عربي بالكامل (RTL إجباري، خطوط عربية، أرقام وتواريخ عربية).

> ليس ثيمًا ولا حزمة أيقونات: هو الشاشة الرئيسية الفعلية للجهاز، يعمل بدون روت وبدون فتح البوتلودر، ويُثبَّت كـ APK عادي، ولا يغيّر نظام أندرويد ولا تطبيقاتك.

## التثبيت والتشغيل

1. ابنِ الـ APK (أو استخدم الجاهز في `app/build/outputs/apk/debug/`):
   ```bash
   cd Launcher
   export ANDROID_HOME=/path/to/android-sdk     # يلزم platforms;android-35 و build-tools;34.0.0
   ./gradlew :app:assembleDebug                  # APK للتجربة
   ./gradlew :app:assembleRelease                # APK الإصدار (تقليص + R8)
   ```
2. ثبّت الملف على الجهاز (Android 8.0 / API 26 فما فوق؛ مُصمَّم ومُستهدَف لأندرويد 15 / API 35).
3. افتح التطبيق: ستظهر شاشة **اختر واجهتك** ببطاقتين وصورة معاينة لكل واحدة. يمكنك **معاينة** الواجهة حيّةً قبل الاختيار.
4. بعد الاختيار تظهر «خطوة أخيرة»: **تعيين كشاشة رئيسية** (يعرض أندرويد نافذة تأكيد رسمية). للرجوع للانشر السابق: إعدادات النظام ← التطبيقات ← التطبيقات الافتراضية ← الشاشة الرئيسية.
5. للتبديل بين الواجهتين لاحقًا: اضغط مطولًا على مكان فارغ في الشاشة الرئيسية ← الإعدادات ← الواجهة. اختصاراتك ومجلداتك وأدواتك تبقى كما هي لأن التخطيط مشترك بين الواجهتين.

توقيع الإصدار: ضع ملف `keystore.properties` بجانب `settings.gradle.kts` بالحقول `storeFile` و`storePassword` و`keyAlias` و`keyPassword`. بدونه يُوقَّع الإصدار بمفتاح التجربة (صالح للتثبيت والاختبار فقط).

## الميزات المنفَّذة

**المحرك المشترك (`launcher-core`)**
- اكتشاف التطبيقات المثبتة ديناميكيًا عبر `LauncherApps` (واجهة اللانشر الرسمية) مع تحديث فوري عند التثبيت/الحذف، ودعم ملفات العمل، دون صلاحية `QUERY_ALL_APPS`.
- إطلاق التطبيقات بحركة تكبير من الأيقونة، معلومات التطبيق، إلغاء التثبيت.
- شاشة رئيسية بصفحات متعددة، شريط سفلي (Dock)، **سحب وإفلات** للأيقونات والمجلدات والأدوات، تبديل الصفحات بالسحب إلى الحافة، صفحة جديدة بالإفلات في صفحة فارغة.
- **مجلدات**: تُنشأ بإفلات أيقونة على أخرى، إعادة تسمية، إخراج تطبيق، فك المجلد؛ المجلد ذو عنصر واحد يتفكك تلقائيًا.
- إزالة الاختصارات (منطقة الإزالة أعلى الشاشة أثناء السحب أو من القائمة).
- **أدوات حقيقية** (App Widgets) من أي تطبيق: اختيار، موافقة الربط الرسمية، شاشة الإعداد الخاصة بالأداة، حجم تلقائي، إزالة.
- حفظ التخطيط في **Room** والتفضيلات في **DataStore**؛ إعادة ترتيب آمنة عند تغيير الشبكة أو الواجهة (لا يُحذف أي عنصر).
- بحث عربي ذكي (يتجاهل التشكيل وأشكال الألف والياء والتاء المربوطة) مع خيار البحث في الويب.
- الخلفيات: خلفيات متدرجة جاهزة، اختيار صورة من المعرض، أو منتقي النظام؛ ألوان النص تتكيف مع الخلفية.
- إعدادات: شبكة (أعمدة/صفوف)، عدد أيقونات الشريط السفلي، حجم الأيقونات، إخفاء الأسماء، الوضع الفاتح/الداكن، أيقونات Material You الأحادية.
- منطقة **تطبيقات النظام**: الحاسبة، الساعة، التقويم، الإعدادات، الهاتف، الرسائل، المعرض — تفتح التطبيق الحقيقي المثبت أو تُخبرك بعدم وجوده؛ لا توجد تطبيقات وهمية.

**واجهة Samsung One UI (`samsung-ui`)**: أيقونات Squircle، ساعة كبيرة في رأس الصفحة، شريط سفلي كحبّة عائمة، درج تطبيقات **مقسّم إلى صفحات** مع شريط بحث **أسفل الشاشة**، انتقال صفحات بتصغير وتلاشٍ، قوائم ضغط مطوّل كبطاقة واحدة، مجلدات بطاقة مركزية، لوحة سريعة بأزرار **دائرية** (٣ أعمدة) مع شريطي السطوع والصوت، ورقة تخصيص سفلية.

**واجهة Google Pixel (`pixel-ui`)**: ألوان **Material You** الديناميكية من الخلفية (أندرويد 12+) مع لوحة بديلة، أيقونات دائرية، أداة «في لمحة» (التاريخ والوقت والبطارية)، شريط بحث **سفلي** فوق الشريط السفلي، درج على شكل **ورقة سفلية** تتبع الإصبع مع بحث علوي وتمرير عمودي، قوائم ضغط مطوّل كأقراص منفصلة، لوحة سريعة بأزرار **أقراص** (عمودان) والسطوع في الأعلى.

**الإشعارات (`notifications`)**: `NotificationListenerService` لا يعمل إلا بعد موافقتك الصريحة؛ تجميع حسب التطبيق، فتح التطبيق الأصلي، إزالة الإشعار (للإشعارات القابلة للإزالة فقط)، مسح الكل.

**الإعدادات السريعة (`quick-settings`)**: كشّاف الضوء (تشغيل فعلي)، السطوع (بإذن «تعديل إعدادات النظام»)، الصوت، التدوير التلقائي، عدم الإزعاج (بإذن الوصول)، وحالة الواي فاي والبلوتوث والبيانات والطيران والموقع وتوفير الطاقة — وأزرارها تفتح لوحات النظام الرسمية (انظر القيود).

**اختيار نمط الإشعارات وشريط الحالة** (الإعدادات ← الإشعارات وشريط الحالة): سامسونج، أو جوجل، أو «الجهاز الأساسي». عند اختيار سامسونج/جوجل يُخفى شريط حالة النظام في الشاشة الرئيسية فقط ويُرسم شريط من اللانشر (الوقت، أيقونات الإشعارات، الواي فاي، البيانات، البطارية)، وتُفتح لوحة النمط المختار بالسحب عليه. عند اختيار «الجهاز الأساسي» لا يُستبدل شيء. مؤشر قوة الإشارة غير معروض لأن أندرويد لا يعطيه إلا بإذن حالة الهاتف الذي لا نطلبه.

**أيقونات تطبيقات النظام بنمط الواجهة**: الهاتف، الرسائل، الكاميرا، المعرض، الحاسبة، الساعة، التقويم، الإعدادات، المتصفح، الخرائط، البريد، الموسيقى تظهر بمجموعة أيقونات Samsung أو Pixel (رسومات أصلية)، وتفتح تطبيقاتك الحقيقية. تطبيقات سامسونج/جوجل نفسها لا يمكن تضمينها أو تنزيلها.

## بنية المشروع

```
Launcher/
├─ app/                 نشاط HOME، الملاحة (Navigation Compose)، شاشة الإعداد الأولي، سجل الواجهات
├─ launcher-core/       النماذج، Room، DataStore، اكتشاف التطبيقات، الأيقونات، محرك الشبكة، LauncherViewModel، واجهة LauncherSkin
├─ shared-components/   مساحة العمل المشتركة (صفحات + سحب وإفلات + مجلدات + قوائم)، منتقي الأدوات، الخطوط العربية
├─ samsung-ui/          واجهة Samsung (كل التخطيطات والحركات خاصة بها)
├─ pixel-ui/            واجهة Pixel (كل التخطيطات والحركات خاصة بها)
├─ notifications/       خدمة الإشعارات + قائمة مجمّعة قابلة لإعادة التنسيق
├─ quick-settings/      متحكم الإعدادات السريعة عبر واجهات أندرويد الرسمية
└─ settings/            شاشة الإعدادات (تبديل الواجهة، الشبكة، الخلفيات، الأذونات، القيود)
```

- **المحرك مشترك والواجهات مستقلة**: `HomeWorkspace` يوفّر السلوك (تمرير، سحب، إفلات، مجلدات)، وكل واجهة تحقن مظهرها عبر `WorkspaceSpec`؛ أما الدرج واللوحة السريعة والقوائم والتحريك فمكتوبة مستقلة في كل واجهة.
- **إضافة واجهة جديدة (HyperOS / ColorOS / OxygenOS)**: أنشئ وحدة تنفّذ `LauncherSkin`، أضفها كاعتمادية في `:app`، ثم أضف سطرًا واحدًا في `SkinRegistry`. لا شيء آخر يتغيّر. (لم تُنفَّذ هذه الواجهات في الإصدار الأول عمدًا.)
- الخطوط: Tajawal لواجهة Samsung، IBM Plex Sans Arabic لواجهة Pixel (كلاهما بترخيص SIL OFL).
- ملاحظة: اقتُرحت وحدتا `app-drawer` و`widgets` منفصلتين؛ دُمجتا عمليًا في وحدات الواجهات (لأن الدرج مختلف تمامًا بين الواجهتين) وفي `launcher-core` (استضافة الأدوات)، لتجنّب وحدات فارغة.

## الأذونات ولماذا

| الإذن | الاستخدام |
|---|---|
| الوصول إلى الإشعارات (يُمنح يدويًا) | قراءة الإشعارات وعرضها وتجميعها وفتح التطبيق الأصلي/إزالتها. يُطلب فقط عند فتح اللوحة وتفعيلها. لا تُرسل لأي جهة. |
| تعديل إعدادات النظام `WRITE_SETTINGS` (يُمنح يدويًا) | السطوع والتدوير التلقائي من اللوحة السريعة فقط. |
| الوصول إلى عدم الإزعاج (يُمنح يدويًا) | تشغيل/إيقاف عدم الإزعاج من اللوحة السريعة. |
| ربط الأدوات | نافذة نظام تظهر عند إضافة أداة من تطبيق آخر. |
| `SET_WALLPAPER` | تطبيق الخلفية التي تختارها. |
| `REQUEST_DELETE_PACKAGES` | خيار «إلغاء التثبيت» (يعرض تأكيد النظام). |
| `EXPAND_STATUS_BAR` | زر فتح لوحة النظام الأصلية (محاولة، قد لا تدعمها بعض الأجهزة). |
| حالة الشبكة/الواي فاي | قراءة الحالة فقط لعرضها في الأزرار. |

لا يطلب التطبيق إذن الإنترنت، ولا الموقع، ولا الكاميرا، ولا جهات الاتصال.

## حدود أندرويد (حقيقية وغير قابلة للتجاوز بدون روت)

1. **لا يمكن استبدال شريط الإشعارات الحقيقي ولا شريط الحالة ولا شاشة القفل.** اللوحة السريعة والإشعارات هنا واجهة داخل اللانشر (تُفتح بالسحب للأسفل من أعلى الشاشة الرئيسية)؛ ويوجد زر لفتح لوحة النظام الأصلية.
2. **تشغيل/إيقاف الواي فاي والبلوتوث وبيانات الجوال ووضع الطيران والموقع وتوفير الطاقة غير مسموح لتطبيقات الطرف الثالث** منذ أندرويد 10. أزرارها تعرض الحالة الحقيقية وتفتح لوحة النظام الرسمية لتغييرها، ولا تدّعي التحكم المباشر.
3. **تطبيقات النظام (الهاتف، الرسائل، المعرض، الساعة...) لا يمكن استبدالها أو تخصيصها**؛ نفتح التطبيق الحقيقي فقط.
4. **إيماءات التنقل وزر الرجوع وشاشة التطبيقات الأخيرة** يتحكم بها النظام.
5. **إشعارات أندرويد 15** قد تُخفي المحتوى الحساس (مثل رموز التحقق) عن مستمعي الإشعارات.
6. السحب المباشر من الدرج إلى الشاشة الرئيسية غير مدعوم؛ استخدم «إضافة إلى الشاشة الرئيسية» من قائمة الضغط المطوّل.
7. تغيير حجم الأدوات يدويًا غير متاح بعد؛ يُحدَّد الحجم تلقائيًا من مقاس الأداة الأدنى.
