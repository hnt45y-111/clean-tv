## 8. طلب HTTP الفعلي لقطعة بث (من Payload في PCAPdroid)
```
GET /hls/da53589eec2e87a64a08968a700f7020/7756_14.ts HTTP/1.1
Cookie: remoTV-Faster
remo: stream-of-REMO
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) ... Chrome/139.0.0.0 Safari/537.36
Accept-Encoding: identity
Host: 192.142.28.22:8089
Connection: Keep-Alive
```
- الرابط الكامل للقطعة: http://192.142.28.22:8089/hls/da53589eec2e87a64a08968a700f7020/7756_14.ts
- الصيغة: HLS. المسار `/hls/<معرّف>/` ثم قطع مرقّمة `7756_14.ts` (القناة أو البث 7756، القطعة 14).
- البث غير مشفّر (HTTP) ويمكن قراءة محتواه على الشبكة.
- **بصمة تمييز فريدة:** التطبيق يرسل ترويسات مخصصة `remo: stream-of-REMO` و`Cookie: remoTV-Faster`، وهي تعمل كمفتاح دخول للسيرفر. ولأن الاتصال غير مشفّر، يمكن لمزوّدي الخدمة كشف هذه الترويسات وحجب الاتصال بها (DPI) دون الحاجة لمعرفة كل العناوين.
- يتنكّر التطبيق بـ User-Agent لمتصفح Chrome على Windows، وهو تمويه.

## 10. رابط قائمة التشغيل الكامل (طلب HTTP رقم 2)
```
GET /live/9127491274/QDXDbuLzFDYaYbD/7756.m3u8 HTTP/1.1
Host: sts.mydroon.com:8080
Cookie: remoTV-Faster
remo: stream-of-REMO
```
الرابط: http://sts.mydroon.com:8080/live/9127491274/QDXDbuLzFDYaYbD/7756.m3u8

الصيغة `/live/<رقم>/<رمز>/<معرّف البث>.m3u8` هي صيغة لوحات **Xtream Codes** الشائعة في بيع اشتراكات IPTV، أي أن:
- `9127491274` اسم مستخدم (حساب اشتراك) مرجّح،
- `QDXDbuLzFDYaYbD` كلمة مرور مرجّحة،
- `7756` معرّف القناة.

المعنى: التطبيق يعمل فوق لوحة IPTV تجارية، وبياناتها مضمّنة أو مشتركة لكل المستخدمين. هذا يوضّح أن صاحب التطبيق يبيع الاشتراك، وأن مشغّل لوحة sts.mydroon.com هو الحلقة الأهم. ملاحظة: هذه بيانات حسابية، فيُحفظ التقرير بسرية ولا يُنشر.
