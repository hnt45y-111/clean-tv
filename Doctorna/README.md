# دكتورنا — حكيم المحلّة، بجيبك

تطبيق صحي عراقي: حجز دور عند الطبيب بأرقام تسلسلية وباركود، ملف طبي، صيدليات وتوصيل، مختبر، مراسلة، تنبيهات دواء، منتدى ومدونة، مكافآت وإحالة، ومساعد صوتي.
الواجهة PWA عربية RTL بالهوية البصرية (لازورد/طابوق/طين، خطوط كوفية، قوس بغدادي، ميل ٩°)، والخادم Node.js بلا أي اعتماديات خارجية.

## التشغيل

```bash
cd Doctorna/server
npm run seed          # يجهّز قاعدة الأدوية + حسابات تجريبية (كلمة السر: 123456)
npm start            # http://localhost:3100  (PORT لتغيير المنفذ)
npm test              # ١٦ اختبار تكامل للخادم
cd .. && node tests/e2e.cjs      # رحلة كاملة بمتصفح حقيقي (يتطلب playwright)
```

يتطلب Node.js ‏22.13+ (يستخدم `node:sqlite` المدمج). عند التشغيل يطبع الخادم عنوان الشبكة المحلية لفتح التطبيق من الموبايل.
أول تشغيل بدون `DOCTORNA_DEMO` ينشئ حساب **المالك** ويكتب بياناته بالملف `server/data/OWNER.txt` (أو حدّد `OWNER_PHONE` و`OWNER_PASSWORD`).

## حدود هذه النسخة (بصراحة)
- **منصة الأدوية**: لا أعرف عنوانها ولا شكل واجهتها. `platform.js` يرسل البيع إلى `DRUG_PLATFORM_URL` (`POST /sales`) بمفتاح `DRUG_PLATFORM_KEY`، وبدونهما يسجّل البيع محليًا. عدّل المحوّل حسب واجهتهم الفعلية.
- **تنبيهات الدواء والتطبيق مغلق تمامًا**: تعمل التنبيهات والتطبيق مفتوح أو بالخلفية عبر الإشعارات المحلية. للوصول والتطبيق مغلق يلزم Web Push (شهادة HTTPS + مفاتيح VAPID) أو نسخة أندرويد أصلية.
- **Siri ومساعد گوگل**: يوجد `POST /api/voice` يمكن ربطه باختصار Siri Shortcuts أو Routines؛ أما «يا گوگل» بدون فتح التطبيق فيحتاج نسخة أصلية.
- **HTTPS**: الكاميرا (قراءة الباركود) والميكروفون وتثبيت PWA تتطلب HTTPS على غير `localhost`.
- **الاشتراك** (نشر المنتدى بلا موافقة): مفتاح اشتراك مجاني حاليًا، بدون بوابة دفع.
- **التوثيق**: يمنحه الأدمن يدويًا بعد التحقق من النقابة.
- **رابط گوگل پلي** في زر «قيّم التطبيق» افتراضي (`iq.doctorna.app`) حتى يُنشر التطبيق.
- المحتوى الطبي بالأمثلة (نصائح السكري/الضغط) للتجربة فقط، ويجب أن يراجعه أطباء قبل الإطلاق.
